# Zerokata — Tic Tac Toe

A two-player Tic Tac Toe game built in HTML/CSS/JS, packaged as an
Android app using MIT App Inventor.

## Features
- 2-player local gameplay
- Light / Dark / Auto theme toggle
- Winning cell highlight animation
- Works in the browser AND as an Android APK

## Play in Browser
Just open `index.html` in any browser — no setup needed.

## Install on Android
Download and open `zerokata.apk` on your Android device.
> You may need to enable **"Install from unknown sources"** in your
> Android settings since this isn't from the Play Store.

## Project Files
| File | Description |
|---|---|
| `index.html` | The full game (HTML/CSS/JS) |
| `zerokata.apk` | Android app installer |
| `zerokata.aia` | MIT App Inventor source project |

## Built With
- HTML, CSS, JavaScript
- [MIT App Inventor](https://appinventor.mit.edu/) for Android packaging
